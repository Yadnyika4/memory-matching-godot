
# 🧠 Memory Matching Game

A fun and interactive 2D Memory Matching Card Game developed using **Godot Engine** and **GDScript**.

The goal of the game is to flip cards, remember their positions, and match all identical pairs in the minimum number of moves and time.

## 🎮 Features

- 🃏 Interactive card-flipping system
- 🍍 Fruit-themed matching cards
- ✨ Smooth card flip animations
- 🔊 Sound effects for flipping, correct matches, wrong matches, and winning
- ⏱️ Game timer
- 🔢 Moves counter
- 🏆 Win detection and message
- 🔄 Restart functionality
- 🎲 Randomized card positions for each game

## 🛠️ Technologies Used

- **Godot Engine 4**
- **GDScript**
- Godot Tween animations
- Godot UI system
- Audio system

## 🎯 How to Play

1. Start the game.
2. Click a card to reveal its image.
3. Click another card to find its matching pair.
4. If the cards match, they remain matched.
5. If they do not match, they flip back.
6. Continue until all card pairs are matched.
7. Try to complete the game with fewer moves and in less time.

## 🚀 Running the Project

1. Install **Godot Engine 4.x**.
2. Clone or download this repository.
3. Open Godot Engine.
4. Select **Import**.
5. Select the `project.godot` file.
6. Open the project and run it.
